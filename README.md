# How to Install and run?

### 1) Create a new folder on your computer named YT-Random-Thumbnails.

### 2) Save the two code blocks above inside the folder as manifest.json and content.js.

### 3) Open Google Chrome or any chrome based browser like brave and type chrome://extensions/ into the URL bar.

### 4) Toggle Developer mode on (top right corner).

### 5) Click Load unpacked (top left) and select your YT-Random-Thumbnails folder.

### 6) Open YouTube. The thumbnails will now display a random mid-video frame instead of the creator's uploaded thumbnail.
